# 철갑 전선

브라우저에서 바로 하는 타워 디펜스입니다. 강철 식민지가 포식 군체의 스무 파도를 막습니다.

포탑은 네 종류입니다. 소총, 화염, 추적, 곡사. 공격력과 연사를 따로 강화하고, 처치한 적에게서 광물을 받습니다. 적이 사령부에 닿으면 목숨을 잃습니다.

## 플레이

1. **방어 개시**를 누릅니다.
2. 아래 포탑을 고른 뒤, 길 옆 칸을 눌러 세웁니다.
3. **플레이**를 누르면 그 파도의 적이 나옵니다.

포탑을 다시 누르면 강화, 판매, 조준(선두 / 근접 / 강적)을 고를 수 있습니다. 한 파도를 한 명도 놓치지 않으면 광물 보너스가 들어옵니다.

## 실행

Node.js 22가 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:8080](http://localhost:8080) 을 엽니다.

기록은 브라우저 `localStorage` 에만 저장됩니다.
